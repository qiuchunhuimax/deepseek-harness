# @deepseek-ai/dsh-client-ui-settings-plugin-inventory

[English](README.md) | 中文

Web 设置中的只读**自建插件**与**插件列表**标签页。浏览器插件注册 id 分别为 `custom` 与 `all` 的本地化 `settings.plugins.tab` 贡献；“插件”分区拥有导航入口与标签栏。插件激活期间不会读取 Remote；首次选择任一标签页时才挂载组件，并通过 [`api-remotes`](../../api/remotes/README.md) 懒调用 `ctx.remote.pluginInventory.list()`。

两个标签页都以可搜索的双列紧凑折叠卡片展示清单。**自建插件**只投影模块全名以本地开发约定 `@dsh-external/` 开头的条目；**插件列表**继续展示完整 Loader 视图。每张收起的卡片使用模块短名称作为标题，以小标签表示有效启停状态；已启用的条目还会以彩色圆点表示根 fiber 状态。展开卡片后会直接展示 Loader 树条目 id，不附加重复的字段标题，并列出有效配置状态；已启用的条目还会列出 Cordis 状态，已停用的条目则省略重复的“未挂载”运行状态。条目 id 仍作为 React key、展开标识、详情值与额外的搜索目标；代码不按该 id 的字符串形状分类。加载、空结果、无匹配结果与通用失败状态只属于已挂载组件；读取失败后可以重试，且不会暴露传输细节。两项注册都使用 `ctx.slots.inject()`，因此能跟随标签 slot 的延迟声明、重新声明、本地化变化与 teardown，而无需 import 分区拥有方。

## 模型体验

无，因为本包只在浏览器设置中展示 Host 拥有的部署快照，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **每个标签页首次挂载或重试时读取一份快照** —— 标签页不订阅 Loader 变化，也不会在重连后自动重新读取；切换标签页会分别保留已挂载的快照，重新打开 Settings 后会在选择标签页时取得新快照。
- **按命名空间识别本地所有权** —— 自建视图只把 `@dsh-external/*` 模块视为本地开发内容，不根据文件系统或 Git 安装详情推断所有权。
- **只读 Loader 视图** —— 本地搜索不会额外引入当前浏览器激活诊断或插件修改控件。
